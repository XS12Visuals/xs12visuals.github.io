# XS12 Visuals — GitHub Pages + Pages CMS

La raíz de este proyecto contiene directamente la web y el archivo `.pages.yml`.

- `index.html` → página de inicio
- `proyecto/` → página del proyecto
- `portfolio/` → portfolio
- `ciencia/` → divulgación científica
- `novedades/` → novedades
- `sobre-mi/` → sobre mí
- `contacto/` → contacto
- `content/` → contenidos editables desde Pages CMS
- `media/` → imágenes gestionadas por el CMS
- `.pages.yml` → configuración de Pages CMS

Para Pages CMS, selecciona el repositorio `XS12Visuals/xs12visuals.github.io`. El archivo `.pages.yml` debe estar en la raíz del repositorio.
